A stripped-back tournament setup

Enter the fog.Own the match.

Four focused pages to run a tournament with plain HTML, CSS and JavaScript. Vercel hosts the pages while Supabase stores the tournament state and broadcasts updates to both streamers and the live overlay.

Open tournament control →Preview live screenBracket screen
01 // BROADCAST

Live Scoreboard

Large team names, live points, round status, toss details and recent results. Add ?overlay=1 for a compact OBS-style overlay.
02 // MATCH CEREMONY

Toss & Draft

Flip the coin, alternate map bans until one realm remains, then let both teams lock a Killer from the randomized five.
03 // MATCH OPS

Bracket & Scoring

Start a bracket match to run the toss and draft first. The action-based points menu opens once the map and both Killer picks are locked.
Storage note: this first version stores tournament state in this browser's local storage and syncs other tabs of the same site origin. Configure Supabase using the included setup SQL and shared/supabase-config.js. Both streamers sign in using their authorized email addresses; the live overlay is read-only and can run on a separate device or OBS browser source.
